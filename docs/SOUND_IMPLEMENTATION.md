# Project 003: BBC Micro Sound Output (Phase 7 audio)
 
The BBC Model B sound path is now implemented:
 
1. `SystemVia6522` models IC32's 8-bit addressable latch. VIA PB0-2 select
   the IC32 output; PB3 sets its level. A high-to-low transition on latch 0
   presents VIA Port A's data byte to the SN76489AN chip.
2. `Sn76489` models eight register latches, three 10-bit tone generators,
   a noise register with a 15-bit LFSR, and four independent 2 dB-step
   attenuators. The input clock is 4 MHz / 16 = 250 kHz, with one chip
   clock per eight host CPU cycles.
3. The renderer generates 44,100 Hz, mono, signed 16-bit PCM in lockstep
   with the existing CPU and 50 Hz video timing.
4. `WindowsWaveOut` submits 20 ms buffers to Windows WinMM on the emulation
   thread. The existing video/CPU loop does not wait on playback. Pause
   resets the queued audio; closing the window releases WinMM resources.
5. When Windows has no audio device, a diagnostic is logged and the emulator
   continues without sound. The CLI headless tests do not require speakers.
 
## Live launch
 
Close any *old* running emulator instance first to release the DLL lock,
then run from the project root:
 
```powershell
Set-Location D:\Emulation\BBCMicro
dotnet run --project src/BbcMicro.Emulator -- --window --scale 2 --disk games/Disc002-ChuckieEgg.ssd --exec "*RUN CH_EGG"
```
 
If the previous build is still running and locking the output DLL, the
**separate audio preview build** can be executed directly:
 
```powershell
Set-Location D:\Emulation\BBCMicro
.\audio-preview\BbcMicro.Emulator.exe --window --scale 2 --disk games/Disc002-ChuckieEgg.ssd --exec "*RUN CH_EGG"
```
 
To test without graphics (sound data still generated but not sent to speakers),
use `dotnet test`. The `Sn76489AudioTests` include latch edge detection,
register writes, sample timing, tone and noise output.

## Troubleshooting
 
- Verify the correct Windows playback device, app volume and system mixer.
- If `[AUDIO] Windows playback unavailable` appears, inspect the
  waveOutOpen error code.
- If the window launches but remains silent, start gameplay, collect
  `[AUDIO] PSG writes / nonzero PCM samples` upon exit, and inspect
  whether tones are written and unmuted; do not fake sound cues.
- Using CMD, change drive and directory with
  `cd /d D:\Emulation\BBCMicro`, not `cd D:\Emulation\BBCMicro`.
 
## Known differences
 
This is a baseline oscillator/noise emulation, not an exhaustive hardware
accuracy claim. Further evaluation should compare the generated tone
frequencies, noise spectra, sample playback and attenuation against original
hardware recordings. On the BBC Micro, audio is generated by the SN76489AN
rather than by Windows Console.Beep.
